## Projects
### MewCo AI Assistant Community
A highly flexible all-round AI assistant with anime-style 2D and 3D effects for web and desktop. Accessible conveniently via browsers across multiple devices and all platforms, AI Assistant Community integrates cutting-edge AI technologies. It is equipped with an active perception dialogue engine, multimodal image recognition, full-range audio perception, multi-agent collaboration, Live2D desktop pets, customizable Live2D/MMD/VRM characters, autonomous PC control, as well as cloud-edge-end three-mode AI engine, delivering a user-friendly and comprehensive AI experience. [Learn More](https://github.com/MewCo-AI/mewco_ai_assistant_comm)
### MewCo AI Assistant Linux
An anime-style 2D/3D AI assistant built specifically for Linux geeks. It integrates a rich set of features including voiceprint recognition-based voice interaction, multimodal image recognition, Live2D/MMD/VRM virtual characters, active perception dialogue, IM bot integration, and three super intelligent agents (OpenClaw/QwenPaw/Hermes Agent), and supports access from any device within the LAN via a browser. [Learn More](https://github.com/MewCo-AI/mewco_ai_assistant_linux)
